# Code of Conduct

We want this to be a friendly, harassment-free project for everyone. Be respectful, assume good intent, give and accept constructive feedback gracefully, and keep discussion about the work. Harassment, discrimination, personal attacks and spam are not tolerated.

Maintainers may edit or remove comments, commits and issues that violate this, and may block repeat offenders. To report a problem, open a private security advisory on GitHub or contact the maintainers through the repository owner's profile.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
